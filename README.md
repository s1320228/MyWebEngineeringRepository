# My Web Engineering Project

## Project Overview

This repository contains the project for the Web Engineering course.

## Development Environment

* Python 3.x
* uv (Python virtual environment)

## Tools

* Black (code formatter)
* Ruff (linter)
* Pytest (testing)
* Pytest-Cov (coverage)

## Project Structure

* `src/` - source code
* `tests/` - test code

## Setup

1. Create a virtual environment:

   ```bash
   uv venv
   ```

2. Activate the virtual environment.

3. Install the required packages.

## Version Control

This project uses Git and GitHub for version control.
